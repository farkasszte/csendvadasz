# The teacher can keep the Noise Meter up over the Scene

Teachers asked to see the room's level live without opening Settings, so a
switch beside the Noise Meter in Settings ("Show on screen") keeps a small
copy of it at the top of the Scene: the same bar, goal line and state as in
Settings, but not the goal slider. It is off unless the teacher turns it on,
it is remembered on this computer like every other setting, and it stays up
when the controls fade, because watching it is the point. While Paused it
gives way to the "Noise meter paused" reminder, since nothing is being judged.

This walks back part of ADR 0001, which kept anything that reacts instantly
to noise off the class's screen, for the same reason ADR 0003 did: teachers
know their rooms. The default is still the Scene alone.

## Considered options

- **Leave the meter in Settings only.** Rejected: the panel covers a third
  of the screen and dims the rest, so the teacher cannot glance at the room's
  level and the Scene at once.
- **Show it only while the controls are visible.** Rejected: the controls
  fade after a few seconds, which is exactly when the teacher wants to look.
- **The goal slider on screen too.** Rejected: it would be one more thing on
  the wall for students to point at, and the goal is set once a lesson.

## Consequences

The class can see the bar jump on a loud moment, which ADR 0001 warns can
become a game. That is the teacher's call to make for their room, which is
why it is a switch and not the default.
